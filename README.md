# 🧬 [Brand Name] — Accessible Biology Workshop Platform

A live, 6-file multi-page web application designed to bring excitement, realism, and luxury design to biology education. Built to serve a millennial audience, the platform balances a high-end editorial aesthetic with absolute pricing transparency—proving that high-grade science education can be accessible without feeling low-end.

---

## 🎨 Design System & Visual Strategy

* **Color Palette:** Anchored by deep plum and aubergine (`#1b1024`, `#2c1c3d`) across structural areas for a luxury feel, accented by metallic gold highlights and an energetic orchid violet built for a lively millennial demographic.
* **Typography:** Features *Cormorant Garamond* (an elegant display serif) for high-impact headlines paired with *Manrope* (a geometric sans-serif) for readable body text—creating a distinct editorial identity.
* **Excitement + Realism:** Leads with high-energy copy backed strictly by concrete data—exact prices, session counts, and strict cohort caps—eliminating vague marketing hype.
* **Transparent Value:** Positions price directly as a core brand pillar via dedicated hero badges, trust strips, and an explicit "Accessibility" value section.

---

## 📁 Architecture & Site Structure

The platform consists of six fully connected static pages powered by a universal shared stylesheet:

1. **Landing Page (`index.html`):** Features the high-impact hero section, core value highlights, the **Our Values** breakdown, and a primary newsletter CTA.
2. **Workshop Catalogue (`workshops.html`):** Full multi-product listing with transparent pricing and filterable workshop categories.
3. **Workshop Detail Page (`workshop-detail.html`):** In-depth single-product page detailing session breakdown, cohort limits, curriculum, and registration.
4. **Contact Page (`contact.html`):** Direct communication hub with embedded newsletter conversion points.
5. **Privacy Policy (`privacy.html`):** Comprehensive legal and data usage document.
6. **Shared Stylesheet (`styles.css`):** Universal CSS file holding design tokens, custom properties, typography rules, and responsive layouts.

---

## 🛠️ Features & UX Highlights

- **Universal Conversion Funnel:** Integrated newsletter subscription CTAs strategically placed across navigation, hero, catalogue, detail, and contact pages.
- **Accessible & Responsive Design:** High-contrast text pairings, touch-friendly interactive targets, and modular layout scaling across desktop and mobile devices.
